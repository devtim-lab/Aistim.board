# Aistim Board

Extension Chrome sederhana yang mengganti halaman tab baru dengan dashboard pribadi. Terinspirasi dari [Muslim Board](https://github.com/novalagung/muslimboard).

## Fitur (v0.1)

- Jam dan tanggal (bahasa Indonesia)
- Sapaan sesuai waktu (pagi/siang/sore/malam)
- Kutipan harian dan warna latar yang berganti per hari
- Daftar tugas (tambah, centang, hapus), tersimpan di `chrome.storage.local`

## Menjalankan secara lokal

1. Buka `chrome://extensions`.
2. Aktifkan **Developer mode**.
3. Klik **Load unpacked**, pilih folder `extension/`.
4. Buka tab baru.

## Rencana berikutnya

- Latar gambar kustom
- Cuaca / lokasi
- Edit tugas, impor/ekspor
- Pengaturan bahasa dan nama
