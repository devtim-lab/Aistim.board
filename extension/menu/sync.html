Token GitHub

Dipakai untuk menyimpan HTML ke devtim-lab/Aistim.board (data/sync.html). Repo itu public, jadi isinya bisa dibaca siapa saja.

Buat di GitHub → Settings → Developer settings → Fine-grained tokens. Pilih hanya repo Aistim.board, izin Contents: Read and write. Token disimpan hanya di browser ini.

Kelola akun

Hanya akun admin yang bisa mengubah daftar. Perubahan ditandatangani dengan passwordmu; extension hanya menerima daftar baru bila ditandatangani admin.

Daftar baru sudah ditandatangani dan dipakai di perangkat ini. Agar berlaku di perangkat lain, simpan sebagai data/akun.json dan data/akun.json.sig di repo.

Masuk ke Aistim.sync

Reset menghapus password dan hasil edit lokal Aistim.sync di perangkat ini. Data di GitHub tidak terpengaruh. Isi lokal tidak bisa dibaca tanpa password, hanya bisa dihapus.

Password Aistim.sync

Hanya hash-nya (PBKDF2-SHA256 lalu HKDF dari SDK, dengan salt) yang disimpan di browser ini, bukan passwordnya. Ini penguncian tampilan di perangkat ini; HTML-nya sendiri tidak dienkripsi.
